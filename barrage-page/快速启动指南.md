# 🚀 快速启动指南

## 📋 依赖包清单

在运行项目前，需要安装以下 npm 包：

### 核心依赖
```bash
npm install vue@^3.4.0
npm install @vueuse/core@^11.0.0
npm install @vueuse/motion@^2.2.0
npm install @tsparticles/vue3@^3.0.0
npm install @tsparticles/slim@^3.0.0
```

### 开发依赖
```bash
npm install -D @vitejs/plugin-vue@^5.0.0
npm install -D typescript@^5.3.0
npm install -D vite@^5.0.0
npm install -D vue-tsc@^1.8.0
npm install -D tailwindcss@^3.4.0
npm install -D autoprefixer@^10.4.0
npm install -D postcss@^8.4.0
```

或者直接运行（推荐）：
```bash
npm install
```

## 🏃 运行步骤

### 1. 进入项目目录
```bash
cd /e/projects/Barrage/barrage-page
```

### 2. 安装依赖
```bash
npm install
```

安装过程中可能需要 1-2 分钟，请耐心等待。

### 3. 启动开发服务器
```bash
npm run dev
```

成功启动后，控制台会显示：
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
  ➜  press h to show help
```

### 4. 打开浏览器
访问：**http://localhost:5173**

## 🔧 常见问题排查

### Q1: npm install 失败
**解决方案**：
```bash
# 清除缓存
npm cache clean --force

# 重新安装
rm -rf node_modules package-lock.json
npm install
```

### Q2: 粒子背景不显示
**检查**：
1. 打开浏览器控制台（F12），查看是否有报错
2. 确认 tsparticles 依赖已正确安装
3. 尝试刷新页面（Ctrl+F5 强制刷新）

### Q3: 动画卡顿
**优化建议**：
1. 关闭浏览器其他占用 GPU 的标签页
2. 确保浏览器硬件加速已启用（Chrome 设置 → 系统 → 使用硬件加速）
3. 如果仍然卡顿，可降低粒子数量：
   - 编辑 `src/components/HomePage.vue`
   - 找到 `particlesOptions.particles.number.value`
   - 将 `60` 改为 `30-40`

### Q4: Tailwind 样式不生效
**检查**：
```bash
# 确认 PostCSS 配置正确
cat postcss.config.js

# 确认 Tailwind 导入正确
cat src/style.css
```

## 📦 生产构建

开发完成后，构建生产版本：

```bash
npm run build
```

构建产物将输出到 `dist/` 目录，可直接部署到静态服务器：

```bash
# 预览生产构建
npm run preview

# 或使用静态服务器（需全局安装 serve）
npx serve dist
```

## 🎨 自定义配置

### 修改配色
编辑 `tailwind.config.js`：
```javascript
colors: {
  'barrage-blue': '#0EA5E9',  // 修改主蓝色
  'barrage-gold': '#FCD34D',  // 修改金色
}
```

### 调整粒子数量
编辑 `src/components/HomePage.vue`：
```typescript
const particlesOptions = {
  particles: {
    number: {
      value: 60  // 修改粒子数量（建议 30-80）
    }
  }
}
```

### 修改按钮尺寸
编辑 `src/components/HomePage.vue`：
```vue
<button class="w-[200px] h-[60px]">  <!-- 修改宽高 -->
```
